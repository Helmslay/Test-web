# Татьяна Лапина — сайт (демонстрационный прототип)

Публичная демонстрационная копия статического сайта. Дизайн и структура пока находятся на стадии согласования.

## Страницы

- Главная — `index.html`
- Индивидуальная работа — `individual.html`
- Групповые форматы — `groups.html`
- О специалисте — `about.html`
- Контакты — `contacts.html`
- Страница 404 — `404.html`

## Локальный просмотр

Откройте `index.html` в современном браузере. Сборка и установка зависимостей не нужны. При наличии интернета загружаются шрифты Lora и Manrope; без интернета используются системные шрифты.

## Важно

- Это прототип, а не готовый production-сайт.
- Форма контактов демонстрационная: она не отправляет и не сохраняет данные.
- Окно «Помощник сайта» — визуальная заглушка, не подключённый чат.
- На страницах используются фотографии Татьяны с прозрачным фоном; биография и часть профессиональных сведений пока остаются на стадии согласования.
- Адреса, стоимость, расписание, биография, профессиональные сведения и отзывы не должны считаться подтверждёнными только на основании этого прототипа.
- На страницах сохранён `noindex, nofollow` на время предпросмотра. Это не ограничивает доступ к публичному репозиторию: содержимое репозитория и сайта доступно всем.

## Проверка

При установленном Node.js:

```bash
node validate.mjs
node --check assets/app.js
```

Статические проверки не заменяют проверку внешнего вида в разных браузерах, на мобильных устройствах и аудит доступности.
